오픈소스소프트웨어 수업에서 Jekyll과 GitHub Pages로 개인 웹페이지를 만들었다.

## 만드는 과정
1. Ruby와 Jekyll을 설치했다.
2. Academic Pages 테마를 포크해서 `juya0.github.io` 저장소를 만들었다.
3. GitHub Actions로 자동 배포를 설정했다.
4. `_config.yml`을 내 정보로 수정했다.
